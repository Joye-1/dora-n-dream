## 数据流

```
用户输入单词 → 本地词典匹配(IndexedDB) → 显示结果
                                    ↓
                            确认添加 → 保存 IndexedDB
                                    ↓
                            联网时 → 同步 Supabase

用户默写 → 本地比对判断 → 错题写入 IndexedDB
                       ↓
                联网时 → 同步 Supabase

用户登录 → Supabase Auth → 拉取云端数据 → 写入 IndexedDB
```

## 离线策略

1. **静态资源**：Service Worker 缓存 HTML/CSS/JS/字体
2. **词典数据**：预装 IndexedDB，完全离线可用
3. **学习记录**：先写 IndexedDB，联网后批量同步 Supabase
4. **发音音频**：Network-First 策略，缓存最近播放的音频
