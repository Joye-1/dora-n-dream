# 产品需求文档 (PRD)

## 产品定位

跨平台雅思背单词应用，支持离线使用，提供多种默写模式进行单词记忆训练。

## 目标用户

- 备考雅思的学生
- 需要系统背单词的英语学习者
- 偏好简约工具型界面的用户

## 核心功能

### 1. 单词管理

| 功能 | 说明 |
|------|------|
| 添加单词 | 输入英文 → 自动匹配 ECDICT 词典 → 显示音标、词性、中文释义、柯林斯星级 |
| 单词列表 | 表格展示：序号、单词、音标、词性、中文意思、发音按钮 |
| 单词详情 | 点击单词进入详情页，展示短语搭配、同义词 |
| 删除单词 | 支持从列表中移除单词 |

### 2. 默写模式（首页原位进行）

| 模式 | 操作 | 判定规则 |
|------|------|---------|
| 拼写英文 | 隐藏英文列，看中文拼英文 | 大小写不敏感，完全匹配 |
| 默写中文 | 隐藏中文列，看英文写中文 | 模糊匹配，答对任意一个中文释义即可 |
| 听音默写 | 隐藏英文和中文列，听读音写英文 | 完全匹配，中文可选不强制 |
| 浏览模式 | 正常显示所有列 | - |

### 3. 每日复习 + 智能抽查

**阶段一：自由复习（必须完成）**
- 展示所有历史单词
- 用户自选默写模式
- 全部完成后解锁阶段二

**阶段二：智能混合抽查（必须完成）**
- 从所有历史单词中筛选 50%-80%
- 筛选权重：错误次数 (60%) + 雅思高频 (40%)
- 三模式随机混合出题
- 完成后显示成绩报告

### 4. 错题集
- 按日期分组显示错题
- 显示错误类型、错误答案、正确答案
- 支持标记已复习、删除
- 错误次数用于智能抽查权重

### 5. 学习统计
- 累计天数、单词数、错题数
- 错题类型分布
- 高频错词 TOP 10

### 6. 云同步
- 邮箱注册/登录
- 数据同步到 Supabase
- 支持离线使用，联网后自动同步

### 7. 短语/同义词管理
- 支持手动添加
- 支持联网查询（Free Dictionary API）
- 标记来源（手动/自动）

## 非功能需求

| 需求 | 说明 |
|------|------|
| 跨平台 | Mac/iPad/Windows 浏览器可用 |
| PWA | 可添加到主屏幕，离线使用 |
| 响应式 | 适配不同屏幕尺寸 |
| 暗色模式 | 支持亮色/暗色切换 |
| 性能 | 词典查询 < 100ms，页面加载 < 2s |
